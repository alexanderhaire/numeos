# Numeos

The privacy policy and support pages for the Numeos iOS app.

Published with GitHub Pages straight out of this repository — there is nothing to
build. The app itself lives in a separate private repository; this one exists so
that two documents App Review requires to be publicly reachable actually are.

- [Privacy policy](https://alexanderhaire.github.io/numeos/privacy.html)
- [Support](https://alexanderhaire.github.io/numeos/support.html)
